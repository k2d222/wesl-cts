# WESL-CTS

Run the WGSL Conformance Test Suite ([CTS]) with [`wesl-rs`].

* `cts/` is a patched version of the CTS.
* `wesl-cpu/` is a 'fake' WebGPU implementation that dispatches shader compilation commands to `wesl-rs-web`.
